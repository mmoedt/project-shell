# Contributing

Thanks for taking a look. This is a scaffold project, so the process here is
deliberately lightweight.

## Reporting a bug

Open an issue using the bug report template. Include what you ran, what you
expected, and what actually happened.

## Submitting a change

1. Fork the repo and create a branch off `main`.
2. Make your change. Keep commits focused — one logical change per commit.
3. Run the test suite: `./tests/test_hello.sh`
4. Open a pull request describing the change and why it's needed.

## Commit messages

Use the imperative mood in the subject line: "Add greeting flag", not "Added"
or "Adds". Keep the subject under 72 characters. If the change needs
explanation, add a blank line and a body.
